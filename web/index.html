Linked Lamps

Direct Bluetooth control over Meshtastic's own GATT link - no phone app, no need to leave the Meshtastic firmware. Injects a lamp packet on the private app port, exactly as a tap on the lamp itself would.
First connection: your OS will show a native Bluetooth pairing prompt - enter 123456 (the lamps' fixed BLE PIN). Chrome/Edge on desktop or Android. On iOS, Safari (and everything else - Apple requires all iOS browsers to use its engine) has no Web Bluetooth support at all - install Bluefy - Web BLE Browser from the App Store and open this page there instead.
